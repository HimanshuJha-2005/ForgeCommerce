# ForgeCommerce storefront (React + Vite)

Customer/seller UI for the ForgeCommerce backend: product browsing with
search, filter, sort and pagination; cart and checkout; order history with
cancel and payment simulation; seller dashboard for categories, products
and stock.

## Run

```bash
npm install
npm run dev   # http://localhost:5173, /api proxied to the backend on :8080
```

The backend must be running first (see the repo README).
Production build: `npm run build`.
